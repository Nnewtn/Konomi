# Konomi AI v2 — клиент-серверное приложение

Интеллектуальное меню и AI-сомелье для ресторана Gęsi Puch (Łódź).
FastAPI-бэкенд + чистый Vanilla JS фронтенд. Никакой рекламы, никаких эмодзи — только тонкие SVG-иконки.

## Структура

```
├── backend/
│   ├── main.py            # FastAPI: /api/menu, /api/weather, /api/chat (+ раздаёт фронтенд)
│   ├── menu.json          # База меню Gęsi Puch (10 позиций, аллергены, описания RU/EN/PL, фото)
│   ├── requirements.txt
│   └── .env.example       # Скопируйте в .env и впишите GEMINI_API_KEY
└── frontend/
    ├── index.html
    ├── style.css          # Дизайн-система: onyx/cream/lime, iOS-glass
    └── app.js             # Каталог, фильтры, шторка ИИ, корзина, голос
```

## Запуск (локально)

```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите GEMINI_API_KEY (опционально)
uvicorn main:app --reload --port 8000
```

Откройте http://localhost:8000 — бэкенд сам раздаёт фронтенд, CORS уже настроен.

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/health` | Статус: какой движок ИИ активен (gemini / rules) |
| GET | `/api/menu` | Полное меню с аллергенами и фото |
| GET | `/api/weather` | Реальная погода Łódź через Open-Meteo (без ключа) + время суток сервера. Кеш 10 мин, безопасный фолбэк при сбое сети |
| POST | `/api/chat` | `{message, context:{lang}, history}` → `{reply, dishes[], combo}` |

## ИИ-движок

1. **Gemini 1.5 Flash** (если задан `GEMINI_API_KEY`): системный промпт получает всё меню, реальную погоду и время суток — сомелье сам делает акцент на согревающих блюдах в дождь, уважает аллергены, отвечает на языке гостя строго в JSON.
2. **Rule-engine фолбэк**: без ключа или при любой ошибке API приложение продолжает полноценно работать — диеты, бюджет, культурные объяснения (kartacze ≈ цеппелины) и генератор комбо −15%.

Валидация ответа модели: фронтенд получает только реальные `id` из `menu.json` — галлюцинации блюд отсекаются на бэкенде.

## Комбо-механика

Сервер (`pick_combo`) и клиент используют одну логику: согревающий суп + фирменное основное + напиток, со строгой фильтрацией по исключённым аллергенам. Скидка 15% применяется одной кнопкой и отражается в чеке.

## Деплой

- Бэкенд — любой хост с Python 3.10+ (Render, Railway, VPS). Фронтенд раздаётся им же.
- Для раздельного деплоя: задайте `ALLOWED_ORIGINS=https://your-frontend` и замените константу `API` в `frontend/app.js`.
